## UI 微调：表格对齐 + 弹窗尺寸

- 表格：Element Plus 树形展开图标是 `inline-block`，而分类/名称单元格是块级 `flex`，图标被挤到文字上方单独占一行，看起来既不垂直居中也不「和文字同级」。修法：`:deep` 让 `.el-table__body-wrapper .el-table__cell .cell` 变 `display:flex; align-items:center`；右对齐列补 `justify-content:flex-end`；展开图标 `align-self:flex-start; margin-top:3px` 与分类主标题同线；缩进 placeholder `flex:none`；分类/名称容器 `min-width:0` 保证 ellipsis 生效。
- 弹窗：`width="760px" top="6vh"` → `width="80%" top="10vh"`，加 `class="item-form-dialog"` 与 `body-class`。因 Teleport 挂到 body，scoped 命中不了，另加一个**非 scoped** style 块：`height:80vh; min-height:560px; margin-bottom:0`（ElDialog 默认 margin-bottom 50px 会吃掉下留白），body `flex:1; min-height:0; overflow-y:auto`；`@media (height <= 700px)` 去掉 min-height 防溢出。
- 验证：vue-tsc / lint / build 通过；dist CSS 已确认含 `[data-v] .el-table__body-wrapper .el-table__cell .cell`、`.item-form-dialog.el-dialog`、`@media (height <= 700px)`。
