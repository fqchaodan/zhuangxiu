## 踩坑与处理

- pnpm 11 不再读 package.json 的 `pnpm.onlyBuiltDependencies`，改用 `pnpm-workspace.yaml` 的 `allowBuilds`。
- 移除 `prepare: husky`（沙箱下 husky 删除 .husky/\_.sh 被 safe-delete 拦截，安装失败）；提交钩子改为手动执行。
- Tailwind 宽度类（`w-56`）对 ElInput/ElSelect 无效，Element Plus 的 `width:100%` 未分层优先级更高，必须用内联 style。
- 给 `ElFormItem` 写成 `ElForm-item` 会渲染异常；模板属性里不能写 `"a" + b` 表达式（Duplicate attribute）。
- 本机 WorkBuddy 的 safe-delete shim 会拦截 Vite 清理 `node_modules/.vite`，启动 dev 需 `NODE_OPTIONS=` 清空注入；普通终端不受影响。
- 分类级联的 v-model 必须是“各级 key 数组”（`getCategoryPath().map(n => n.key)`），不能用 `key.split('.')`。

## 部署：子目录 /renovation/ 的 base 问题

- 线上地址 `https://env-00jy6y3evqim-static.normal.cloudstatic.cn/renovation/index.html`，但首屏 JS 请求的是 `/assets/*`（丢前缀）→ 404 白屏。
- 根因：`.env.production` 里 `VITE_BASE_URL = /`，覆盖了 `.env` 的 `/renovation/`，Vite 打包产出根绝对路径。
- 修复：`.env.production` 改为 `VITE_BASE_URL = /renovation/`，重新 build，产物 index.html 及 JS 内资源全部带 `/renovation/` 前缀。路由是 hash 模式，无需再配 router base。
- 沙箱注意：`pnpm build` 会因 safe-delete 拦截「清空 dist（173 文件）」而失败，可 `vite build --outDir dist-xxx` 再同步进 dist。
